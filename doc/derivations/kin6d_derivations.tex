\begin{abstract}
These notes derive the KIN6D components that the repository did not yet
derive: governing equations and weak forms, discretisation, boundary
conditions and free-boundary coupling, Newton linearisations, expected
convergence orders and diagnostic definitions. Every equation attributed to
the code cites \src{file:line}; the commit is stated at the start of each
section (code on unmerged branches is cited at the branch commit). Each
section ends with a verification table: derivation against code, numerical
checks with observed orders, and candidate bugs, which are also marked inline
in red boxes. Orange boxes mark statements the code does not let us verify.
\end{abstract}

# Whole-cell exact-reference GS validation

- Scope: retained P1 fields versus the known Solovev solution on the retained
  polygon. This is an exact-reference enclosure, not an arbitrary-source GS
  solution certificate. No PDE state, interpolation basis or solver is changed.
- Inputs are exact stored binary64 coordinates/nodal fluxes and declared
  binary64 reference parameters. Assume a valid nonoverlapping native mesh.
  Decimal input conversion, mesh validity and physical input uncertainty remain
  separate premises; this checker does not prove them.
- `gen/gen_gs_reference_error.f90` retains the mathematical kernel and proves
  ten exact GS/Maxwell-stress identities. Generated interval leaves use the
  pinned FortNum outward arithmetic, with no fast math or FMA contraction.

## Quantities

Let `Omega` be the retained RZ polygon, `R>0`, and

\[
 \psi_* = C[(R^2-R_0^2)^2+4R^2Z^2]-\psi_e,\quad
 F_*=F_h=F_0,\quad p_*=-16C\psi_*/\mu_0.
\]

- Native reconstruction: the unique continuous P1 function `psi_h` from the
  stored mesh. Its gradients are piecewise constant; no Hessian or smoothing.
- Fields: `B=(-psi_Z/R, F/R, psi_R/R)` in the orthonormal `(R,phi,Z)` frame.
- Candidate pressure: `p_h=pprime*psi_h`, the E0 constant-source zero-edge
  law. Small received/source rounding differences are not fitted away.
- This is the mathematical P1 field, not a claim that each separately rounded
  exported field sample equals its exact derivative bit for bit.

The checker encloses

\[
 I_B=\int_\Omega |B_h-B_*|^2\,dR\,dZ,\qquad
 I_E=\int_\Omega |\nabla(\psi_h-\psi_*)|^2/R\,dR\,dZ.
\]

- Area RMS field error is `sqrt(I_B/area(Omega))`.
- A whole-cell field supremum bound covers both one-sided traces at interfaces.
- Toroidal volume is `2*pi*integral(R dR dZ)`; field energy uses this physical
  volume element, not an unweighted count of mesh centroids.

## Distributional current bound

For every zero-boundary scalar test `v` in `H0^1(Omega)`, integration by parts
includes the P1 cell `1/R` current and interior gradient-jump current:

\[
 \mu_0\langle j_{\phi,h}-j_{\phi,*},v\rangle
 =\int_\Omega \nabla(\psi_h-\psi_*)\cdot\nabla v/R.
\]

- In the weighted test norm `||v||_a=sqrt(integral(|grad v|^2/R))`, the dual
  current error is at most `sqrt(I_E)/mu0`, units `A sqrt(m)`.
- Its lower bound is zero: the energy norm need not equal this dual norm when
  the analytical restriction and P1 field have different boundary traces.
- This is a weak current bound, not a pointwise current or axis-Hessian bound.
- Cell/jump/boundary signs are checked independently by the P1-current tests.

## Weak physical force bound

On the toroidal volume generated by `Omega`, define Maxwell stress

\[
 M(B)=(BB^T-|B|^2 I/2)/\mu_0,\qquad S=M(B)-pI.
\]

The analytical reference has `div S_*=0`. The P1 candidate force is the
distribution `div S_h`, including stress jumps. For zero-boundary Cartesian
vector tests `w`,

\[
 |\langle f_h,w\rangle|\le
 \|S_h-S_*\|_{L^2(V)}\,\|\nabla w\|_{L^2(V)}.
\]

- The reported force-dual upper bound is `sqrt(2*pi*integral(R*|S_h-S_*|_F^2))`,
  units `N/sqrt(m)`. Rotation of the orthonormal frame preserves this norm.
- Its lower bound is zero; this majorant is not the actual dual-norm value.
- Do not multiply an unspecified edge-current distribution by a discontinuous
  field. The Maxwell-stress distribution defines the weak force explicitly.
- A weak force majorant is not a local force density or a strong-force bound.

## Enclosure and independent gates

- Subdivide each exact triangle into four midpoint children. At terminal
  depth, interval RZ boxes cover each child; evaluate the generated densities
  on the entire box and multiply by its enclosed exact area.
- All gradients, subdivision coordinates, areas and sums use outward intervals.
  Clipping a density's lower endpoint to zero uses its proved sum-of-squares
  nonnegativity. Upper endpoints are never reduced by sampled values.
- Independent affine fixture: `psi_h=R-1`, zero reference, triangle vertices
  `(1,0),(2,0),(1,1)`. Exact integrals are `I_B=1-log(2)`,
  `I_E=2log(2)-1`, and `integral(R*|delta S|^2)=3/16` for `mu0=1`.
- Tests require enclosure, tightening under subdivision, reversed winding and
  rejection of `R<=0`. Numerical integration of complete E0 meshes is a
  separate optional oracle, not the source of any interval endpoint.
- Polygon geometry/trace error remains separate. These enclosures cover the
  exact reference restricted to the polygon, not missing physical volume.
- For unknown equilibria an independent residual/stability and boundary-lifting
  theorem is still required. These exact-reference checks do not supply it.

## Run

- Build target `gs_reference_error`; registered test
  `grad_shafranov_reference_cell_enclosures` in Release and checked Debug.
- `gs_reference_error mesh.dat reference.nml` reads native one-based mesh
  connectivity and `/gs_reference/ r0,c,edge,f,mu0,pp,depth`.
- Printed current/force intervals are `[0, upper_bound]`; field-energy
  intervals enclose the corresponding actual reference-error norm.
- TC24 repository retains the three exact-case inputs, receipts and optional
  independent 8/12-order triangle-quadrature replay. No production PDE rerun.
